Vet Patient Capture — Privacy Policy

Last updated: July 31, 2026

What this extension does

Vet Patient Capture lets a veterinary clinician manually capture text, images, or other files from web pages they are actively viewing (such as browser-based scribe apps or practice management software), tag that captured material with patient name, doctor name, date, and intended use, and hold it locally for the clinician's own later use — including optionally handing it off to a Claude AI chat session that the clinician opens themselves.

What data is collected

The extension only captures data the user explicitly provides, through one of these actions:

  • Text the user selects on a web page and either right-clicks to capture, or that is present on the page when the user opens the extension popup
  • Text the user types or pastes directly into the extension's popup
  • A file (image, PDF, document, or other file type) the user explicitly chooses to upload through the popup's file picker
  • Metadata the user types into the tagging form: patient first/last name, doctor first/last name, date, and intended use

The extension does not passively monitor, log, or transmit browsing activity. It only acts on a page when the user actively triggers a capture (right-click menu, opening the popup, or pasting/uploading content into it).

Where data is stored

All captured data is stored locally on the user's own device, using the browser's built-in chrome.storage.local API. Nothing is sent to any server operated by the extension's developer. The developer has no access to, and does not receive a copy of, any captured data.

How data may leave the device

Data only leaves the local browser storage when the user takes one of these explicit actions:

  • Copy: the user clicks "Copy," which copies text to the system clipboard using the standard browser clipboard API.
  • Download: the user clicks "Download," which saves an uploaded file back to the user's own device using the browser's file download mechanism.
  • Send → Desktop: the user clicks this action, which opens the Claude Desktop application (if installed) via a claude:// deep link, with a text prompt pre-filled. This hands the data to Claude Desktop, an Anthropic product the user has separately chosen to install and use, and which has its own privacy policy.
  • Send → Browser: the user clicks this action, which copies a text prompt to the clipboard and opens a new tab to claude.ai. The user must manually paste and send the content themselves; the extension does not transmit anything automatically. claude.ai is an Anthropic product with its own privacy policy.

In all cases, sending data to Claude Desktop or claude.ai is a deliberate, one-at-a-time action taken by the user, not something the extension does automatically or in the background.

Permissions used

  • storage / unlimitedStorage: to save captured items locally on the user's device so they persist between browser sessions.
  • contextMenus: to add the "Capture selection to Vet Extension" right-click menu option.
  • activeTab: to read the currently active tab's URL (stored alongside a capture for reference) and to open new tabs for the Send actions.
  • host permissions (all sites): the content script that detects a page's current text selection must be able to run on any site, because the clinician may use this extension on a wide range of veterinary software and scribe applications hosted on many different domains, which cannot be known or restricted in advance.

Remote code

This extension does not download or execute any remotely hosted code. All code that runs is packaged within the extension itself.

Data retention and deletion

Captured data remains in local browser storage until the user deletes it using the "Delete" action in the extension, or until the user removes the extension or clears their browser's extension storage.

Contact

Questions about this policy can be directed to the developer at the contact information provided on this extension's Chrome Web Store listing.
